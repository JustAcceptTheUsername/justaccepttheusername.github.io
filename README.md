# justaccepttheusername.github.io

Developer site for BlockBloom.

| URL | Use |
|-----|-----|
| https://justaccepttheusername.github.io/ | Developer website (store listings, AdMob account) |
| https://justaccepttheusername.github.io/privacy/ | Privacy Policy (Integration Manager, Play Console, App Store Connect) |
| https://justaccepttheusername.github.io/app-ads.txt | Ad network authorization (must stay at the root) |

## Before publishing
- Fill `app-ads.txt` with the line from AdMob (Apps → app-ads.txt).
- Read the privacy policy and adjust if the app's data use changes (e.g. new ad networks).
